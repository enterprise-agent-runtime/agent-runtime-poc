# Architecture Decision Records (ADRs)

Use ADRs to capture irreversible or high-impact technical decisions.

## Naming

`ADR-XXX-short-title.md`

Examples:

- `ADR-001-runtime-language.md`
- `ADR-002-agent-manifest-format.md`
- `ADR-003-sandbox-strategy.md`

## Why ADRs

- preserves decision context
- avoids re-litigating prior decisions
- improves onboarding and auditability
