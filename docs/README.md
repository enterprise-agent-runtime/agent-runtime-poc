# Enterprise Agent Runtime Documentation

This repository contains the versioned product and technical documentation for the **Enterprise AI Agent Runtime Platform**.

## Purpose

This repo is the canonical source for:

- Product vision and strategy
- POC and MVP specifications
- Enterprise architecture
- Architecture Decision Records (ADRs)
- Roadmap and release transitions

## Document Flow

1. `docs/00-product-vision.md`
2. `docs/01-poc-specification.md`
3. `docs/02-poc-results-and-mvp-specification.md`
4. `docs/03-mvp-implementation-specification.md`
5. `docs/04-enterprise-architecture.md`

## Principles

- Keep docs **Markdown-first** for version control and collaboration.
- Generate `.docx`/PDF from Markdown for external sharing.
- Record major technical decisions as ADRs under `decisions/`.
- Treat this repo as the **single source of truth** for phase transitions.

See `docs/versioning.md` for document lifecycle and status definitions.
