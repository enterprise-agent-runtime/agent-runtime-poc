| D-045 | 2026-10-16 | How does the CLI keep text it did not write from controlling the terminal (CWE-150)? | New stdlib-only package `internal/termsafe`.

**`SanitizeDetail`** is used for human output:

- It removes escape sequences whole: CSI, OSC/DCS/SOS/PM/APC, and their C1 forms. A control string ends where a terminal ends it (BEL, ST, CAN, SUB, ESC, any C1).
