| D-009 | 2026-10-04 | ULIDs and RFC 8785 JCS without `oklog/ulid` and `gowebpki/jcs`. | Small stdlib implementations: `internal/ids` (ULID, monotonic within a millisecond, `crypto/rand`) and `internal/store/jcs` (RFC 8785 canonical JSON, tested against the RFC's examples). | Neither library is in `CLAUDE.md` §4; both algorithms are short and fully specified. | A04, A17; CONFLICTS C-33 |
| D-010 | 2026-10-04 | Encrypted-file secrets backend format and unlock. | `~/.warden/secrets.enc` (or `%LOCALAPPDATA%\Warden\secrets.enc`), mode 0600: JSON `{v:1, kdf:"pbkdf2-sha256", iter:600000, salt, nonce, ct}`; key = PBKDF2-HMAC-SHA-256(passphrase, 16-byte salt, 600,000 iterations, 32 bytes) from stdlib `crypto/pbkdf2`; AES-256-GCM over the JSON map of account → value; rewritten atomically (temp + rename) with a fresh nonce on each change. The daemon starts **locked**; NEW method `secrets.unlock {passphrase}` (CLI `warden unlock`, no-echo prompt) unlocks it for the daemon's lifetime; methods needing a secret while locked fail with NEW error `-32013 secrets_locked`. The passphrase is never stored, logged or accepted from an environment variable. | CLAUDE.md §3 fixes the backend but no document defines its format; stdlib only. | CLAUDE.md §3; A15; CONFLICTS C-12 |
| D-011 | 2026-10-04 | Windows transport details. | Named pipe `\\.\pipe\warden-<user>` created with `go-winio` and SDDL `D:P(A;;GA;;;<owner SID>)` (owner-only, no inheritance; also denies remote clients via the pipe's default reject-remote flag). Token file `%LOCALAPPDATA%\Warden\run\token` written by the daemon with an owner-only ACL. Single-instance: the pipe name itself (a second daemon fails to create the first instance). | CLAUDE.md §4 IPC; no design document covers Windows. | CLAUDE.md §3–§4; CONFLICTS C-07 |
| D-012 | 2026-10-04 | Terminal input without echo (API keys, passphrase) without `golang.org/x/term`. | `internal/platform.ReadSecretLine` toggles echo with the stdlib: `ioctl(TCGETS/TCSETS)` on Linux, `TIOCGETA/TIOCSETA` on macOS, `GetConsoleMode/SetConsoleMode` on Windows.
